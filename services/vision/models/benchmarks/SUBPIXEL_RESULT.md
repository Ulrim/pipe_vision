# 끝단 서브픽셀 추정기 벤치마크 (2026-10-20)

재현: `cd services && python -m vision.tools.subpixel_benchmark --seeds 100 [--md 표.md --json 원자료.json]`
(결정적, 이 PC 약 10분). 아래 수치는 그 결과에서 골랐다. 단위는 **px**(끝단 하나 또는 길이).

## 결론

1. **끝단 위치는 선형 그레이에서 잰다.** 반사 보정본(조명 나눗셈 + CLAHE + 3×3 미디언)에서 재면
   어떤 추정기든 길이가 0.4~0.6px 틀린다. 조명 나눗셈이 끝단에서 화소마다 크게 바뀌는 이득을
   곱하고(200행 합성 프레임·다발 crop 에서 화소당 ~10%), 미디언이 끝단 옆 후광을 깎으며 끝단에
   걸친 화소를 평탄부처럼 만들어 화소 사이 정보가 **지워진다**. 찾기·가드는 보정본 그대로,
   위치만 `PreprocessResult.gray` 에서 잰다.
2. **추정기는 대칭 창 기울기 무게중심**(`vision/length/subpixel.py`) 하나로 세로평균
   (`measure._find_edges`)과 행별 적합(`edges._row_subpixel`) 모두를 잰다.
   3점 중앙값(1px 반짝임 제거, 단조 끝단은 그대로) → 중앙차분(반대 부호 버림) → 포물선 첫 추정 →
   추정을 중심으로 한 ±3px 창(가장자리 화소는 겹친 비율만큼)의 무게중심, 2회.

| 항목 | 종전 | 채택 |
|---|---|---|
| 파이프라인 길이 최대 오차, 합성 막대 σ 0 / 0.8 / 1.2 | 0.394 / 0.480 / 0.501 | **0.006 / 0.012 / 0.017** |
| 끝단 S자 최대(8비트, 노이즈 0), σ 0.5 / 0.8 / 1.2 / 2.0 | 0.045 / 0.043 / 0.031 / 0.050 | **0.005 / 0.008 / 0.010 / 0.020** |
| 같은 것, 양자화 없음(추정기 자체) | 0.039 / 0.038 / 0.025 / 0.011 | **0.000 / 0.001 / 0.003 / 0.002** |
| 노이즈 σ(5계조), σ 0.8 / 1.2 / 2.0 | 0.099 / 0.196 / 0.464 | **0.084 / 0.099 / 0.168** |
| \|오차\|>1px(1D 전체 126,630건) | 956 | **0** |
| `test_end_detection_is_subpixel`(블러 없음) | ±0.25 허용, 최대 0.200 | **±0.01 허용, 0.000** |

종전 = 행별 기울기 3점 포물선(측정을 덮어쓰는 경로; 세로평균 경로의 평활 포물선은 S자 0.022~0.028).
실제 광학 0.072mm/px 로 환산하면 종전 파이프라인 오차 0.48px = **0.035mm(±0.1mm 공차의 35%)**,
채택 0.012~0.017px ≈ 0.001mm. 조명 나눗셈 커널은 영상 크기에 비례해 큰 단일 프레임에서는
덜 틀어지지만, 다발 검사는 튜브 crop(수십~수백 행)마다 전처리하므로 그대로다.

## 조건

- 1D: 화소 면적 적분(화소 k 가 [k−0.5, k+0.5])한 가우시안 블러 계단을 erf 적분으로 **해석적으로**
  그림. 배경 30·제품 185, 8비트 양자화, 위상 0~1(0.05 간격) × 상승·하강, 노이즈 0/2/5 계조 × 100시드.
  블러 σ 0(참고: 시험 합성)·0.5·0.8·1.2·2.0. 테두리 반짝임 = 끝단 안쪽 1px 이 +25(gen_synthetic
  끝단 선 210 vs 몸체 185) 또는 +60.
- 길이: 같은 렌더의 60행 막대(길이 500+위상, 두 끝단 위상이 따로 돎)를 `measure_length_ex` 에,
  세로로도 블러한 200×900 프레임을 `InspectionPipeline` 에.
- 후보 10종: parabola_smooth·parabola_raw(현행 두 경로), gauss_smooth(평활 기울기 로그-포물선),
  centroid(정수 극값 ±2 고정 창 무게중심), mid50_linear(좌우 중앙값 레벨 50% 교차, 선형 보간),
  mid50_symmetric(+추정 기준 대칭 재읽기), mid50_med_box3(+3점 중앙값·평균 후), area_adaptive(부분면적,
  끝단 폭에 맞춘 창), esf_fit(erf 계단 4변수 가우스-뉴턴, 기준용), **centroid_symmetric(채택)**.

## 4. 남는 한계 — 테두리 반짝임

1px 반짝임은 **모든** 추정기를 바깥으로 끈다. +25 에서 끝단 하나 최대가 대부분 0.13~0.20(채택 ≤0.169,
종전 행별 ≤0.200), +60 에서 대부분 0.23~0.40(고정 창 centroid·mid50_linear 는 넓은 블러에서 더 크다). 블러가 반짝임보다 넓으면 반짝임은 끝단 질량의 일부라 구분할 정보가 없다.
화소에 딱 맞은 1px 선(gen_synthetic)은 3점 중앙값이 지운다 — 다발 합성 125.012~125.014mm(참 125.000).
반짝임이 강하면(+60, σ≥0.5) 미분 3점짜리 parabola_raw 가 덜 끌린다(평균 0.18~0.30 vs 채택 0.24~0.34)
— 그 대가로 반짝임 없는 끝단의 S자·노이즈·실패가 위 표처럼 나쁘다. 렌즈 왜곡 합성(재매핑으로 반짝임이
화소 사이에 걸림, k1 −0.05~−0.3)의 해석해 대비 최대 오차: 종전 0.197mm, mid50_med_box3 0.158mm,
**채택 0.139mm**. 실물 끝단(버·모따기)의 반짝임 크기는 MSA 기준 시료로만 확인할 수 있다.

## 5. 왜 이것인가

- **mid50_med_box3(차점)**: S자·노이즈가 비슷하지만 1D 호출이 2.8배 느리고(283 vs 102µs), 반짝임이
  3점 평균으로 바깥 화소까지 번져 렌즈 합성에서 더 틀린다(0.158 vs 0.139mm).
- **area_adaptive**: 깨끗한 계단에선 정확하나 끝단 옆 밝기 구조(후광·반짝임 질량)를 그대로 적분한다 —
  보정본에서 1.19px, 반짝임 +60 에서 평균 0.33~0.38.
- **gauss_smooth**: σ0.5~1.2 에서 좋지만 블러 없음 0.029·σ2 0.036, 넓은 블러에서 노이즈 σ 0.30·실패 11.
- **esf_fit**: 기준으로는 최선(양자화 없으면 0)이나 1.26ms/호출이고 모델 밖(블러 없음·반짝임)에서 발산.
- 채택은 극값 화소 ±1 어긋남에 불변, 상승/하강 거울 대칭(1e-9), 국소 밝기·대비 무관, 고정 횟수(결정적).

## 6. 시간 (이 PC)

추정기 호출 고정비 ~0.1ms(1D 0.10ms), 행 묶음은 행당 1.5~2.3µs 가 더해진다(정수 끝단 ±8px 만 떼어
계산). 튜브마다 세로평균 1회 + 양 끝단 행 묶음 1회 = 2회 호출이라, 종전(행마다 파이썬 포물선 ~1µs)
보다 튜브 하나 길이 측정(90행)이 0.75 → 1.07ms, 다발 20개 한 프레임이 41 → 48~50ms 로 늘었다
(min-of-7, HEAD 대비). 단일 튜브 프레임 ~5ms 는 그대로. 처리속도 목표 300ms/ea 안이다.
