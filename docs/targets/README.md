# 인쇄용 보정 타깃

여기 PDF 를 **배율 100%(실제 크기)** 로 인쇄해서 쓴다. 생성기는
`services/vision/tools/make_targets.py`, 치수 검증은
`services/vision/tests/test_make_targets.py` 에 있다.

| 파일 | 용도 | 용지 | 규격 |
|---|---|---|---|
| `checkerboard_A4_9x6_20mm.pdf` | 렌즈 왜곡 보정 | A4 가로 | 내부 코너 9×6, 칸 20mm |
| `checkerboard_A3_9x6_30mm.pdf` | 렌즈 왜곡 보정(권장) | A3 가로 | 내부 코너 9×6, 칸 30mm |
| `gauge_A4_10mm.pdf` | 길이 기준자 | A4 가로 | 마크 27개 @10mm, 스팬 260mm |
| `gauge_A3_10mm.pdf` | 길이 기준자(긴 제품) | A3 가로 | 마크 39개 @10mm, 스팬 380mm |
| `gauge_A4_5mm.pdf` | 길이 기준자(조밀) | A4 가로 | 마크 53개 @5mm, 스팬 260mm |

## 인쇄 — 여기서 틀리면 전부 틀어진다

인쇄 대화상자에서 **"실제 크기" / "100%"** 를 고르고 **"용지에 맞춤"을 끈다.**
기본값이 "맞춤"인 프린터가 많아서, 그대로 누르면 94~97% 로 줄어든다.

인쇄 후 **시트 아래쪽 `VERIFY SCALE` 선을 자로 재라.** 바깥 눈금 두 개의 중심
사이가 정확히 **200.00mm** 여야 한다. 다르면 배율이 틀어진 것이니 다시 인쇄한다.

## 두 타깃은 정확도 요구가 다르다 — 중요

### 체커보드: 인쇄 배율 오차가 거의 문제되지 않는다

렌즈 왜곡 계수는 무차원이고 보드의 **모양**에서 나온다. 칸이 균일하게 0.3%
작게 인쇄돼도 왜곡 추정은 그대로다.

대신 **평평함이 치명적이다.** 종이가 휘면 모양이 깨져 왜곡으로 오인된다.
→ 포맥스·아크릴·알루미늄 판에 **주름 없이** 붙여라. 책받침에 테이프로 네 귀퉁이만
붙이면 가운데가 뜬다. 전면 접착(스프레이 본드)을 권한다.

### 기준자: 인쇄 배율 오차가 곧바로 측정 오차다

눈금 간격이 길이 환산의 기준이기 때문이다. 프린터 오차 ±0.3% 는 250mm 에서
**0.75mm** — ±0.1mm 공차의 7배다.

해법은 "정확히 인쇄하기"가 아니라 **"인쇄된 실제 값을 재서 그 값을 쓰기"** 다.

1. 인쇄해서 평평한 판에 붙인다.
2. **캘리퍼로 양 끝 눈금 중심 사이(스팬)를 잰다.** 시트에 기입란이 있다.
3. `간격 = 측정스팬 ÷ (마크수−1)` 을 계산해 `AIVIS_FIDUCIAL` 에 넣는다.
   예) A4 10mm 시트(마크 27개)에서 스팬이 259.6mm 로 나왔다면
   `259.6 ÷ 26 = 9.9846` → `AIVIS_FIDUCIAL=9.9846:0,0,4608,220`

> **인쇄물은 임시방편이다.** 종이는 습도에 따라 0.1~0.2% 늘고 줄며, 그것만으로
> 250mm 에서 0.25~0.5mm 다. 양산에서는 **강재 자나 유리 눈금자**를 쓰고, 그
> 성적서의 값을 넣어라. 인쇄물은 셋업·시운전용으로 충분하다.

## 촬영·설치 요건

- 기준자는 **제품 상면과 같은 높이**에 둔다. 바닥판에 두면 튜브 OD 의 절반만큼
  평면이 달라 250mm·작업거리 500mm·OD 12mm 에서 **3mm** 계통오차가 난다.
  **품목이 바뀌어 OD 가 달라지면 기준자 높이도 바꾼다.**
- 기준자는 제품 양 끝보다 **길어야** 한다. 마크 바깥은 외삽이라 이점이 사라진다.
- 카메라 ROI 는 **마크 행 중심 ±15mm 안**으로 잡는다. 그 바깥의 글자·눈금이
  ROI 에 들어오면 연결성분이 늘어 간격 적합이 깨진다(시트는 이 정숙 구역을
  비워 두도록 배치돼 있다).

## 다른 규격이 필요하면

```bash
cd services/vision
python -m vision.tools.make_targets checkerboard \
    --cols 9 --rows 6 --square-mm 25 --page a3 --out /tmp/board.pdf
python -m vision.tools.make_targets gauge \
    --pitch-mm 20 --page a3 --out /tmp/gauge.pdf
```

`--cols`/`--rows` 는 **내부 코너 수**다(칸 수가 아니다). 10×7 칸 보드면 9×6.
홀수×짝수여야 한다 — 짝수×짝수는 180° 돌린 것과 구분되지 않아 코너 순서가
뒤집힐 수 있다(도구가 거부한다).

**생성기를 고쳤으면 `docs/targets/` 파일도 다시 뽑아 커밋하라.** 어긋나면
`test_committed_pdf_matches_the_generator` 가 실패한다.
